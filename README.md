## 🇫🇷 Français

**Playlist Manager** est une application de bureau (Windows/Mac/Linux) qui permet de :
- 🔍 Rechercher des playlists YouTube
- ▶️ Écouter la musique directement dans l'app
- ⬇️ Télécharger les pistes en MP3 avec les tags (titre, artiste)
- ⭐ Sauvegarder des playlists en favoris

### Prérequis
```bash
pip install yt-dlp pywebview mutagen pygame
```
Il faut aussi installer **ffmpeg** et l'ajouter au PATH : https://ffmpeg.org/download.html

### Lancement
- Double-clic sur `manager.pyw` (Windows)
- Ou en ligne de commande :
```bash
python manager.pyw
```
